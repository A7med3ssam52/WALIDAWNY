# Sub Agent: videos-qa

## الفكرة (الميزة كاملة)

ثلاثة أهداف مكتملة من agents سابقين: (1) رفع فيديو في الخلفية (SW + manager)، (2) فيديوهات متعددة للدرس، (3) فيديوهات يوتيوب باللينك. انت **التحقق النهائي**: شغّل كل شيء، أصلح أي خلل، حدّث الوثائق، وتأكد أن `supabase-full-schema.sql` = 42 markers.

## نطاقك

1. تشغيل كل التحققات (أدناه) وإصلاح أي خطأ — أي ملف، بأي تمن.
2. الوثائق: `ARCHITECTURE.md` / `DATABASE.md` / `SECURITY.md` / `README.md` (بند الميزة) / `reports/videos-test-report.md` (جديد — تقرير نهائي بنمط تقرير السبورات).
3. **`supabase/supabase-full-schema.sql`** — تأكد 42 markers واتساق التعليق الرأسي (قد يكون منجزاً من videos-db — تحقق فقط، وأصلح لو ناقص).
4. **ممنوع:** git commit/push — التحميل مركزي لاحقاً.

## خطوات التحقق (شغّلها كلها من الصفر)

1. **SQL harness:** `npm start` في `supabase/tests/local` → الميجريشنز 0001→0042 كلها PASS + **14 suite** (01..12 + 2 concurrency) كلها PASS → ALL GREEN.
2. **Deno:** `deno test supabase/functions` → كل الوظائف (≥293 + تحديثات create-video-upload-session/get-video-playback-url) بلا فشل.
3. **Frontend:** `npm run typecheck` + `npm run lint` + `npm run test` (≥274 + اختبارات upload/tusCore/يوتيوب/المتعدد) + `npm run build`.
4. أصلح أي خطأ يظهر وأعد التحقق حتى الكل أخضر.
5. افحص `git status`: التغييرات كلها ضمن النطاق (لا تعديلات عشوائية على ميجريشنات قديمة/EFs/ملفات واجهات غير مقصودة).
6. حدّث الوثائق أعلاه + اكتب `reports/videos-test-report.md` (بنمط `reports/boards-test-report.md`: جدول النتائج الدقيقة + ما تم بناؤه + ملاحظات متبقية).

## القواعد

- لا تغيّر سلوكاً خارج نطاق الميزة (لا إعادة هيكلة، لا RTL، لا تنسيق).
- أخطاء واجهات/EFs: أصلحها في مكانها بأقل تدخل — لو الخطأ سببه تعارض دالتين في نفس الملف من agentين، وفّق بينهما بذكاء (كلا الهدفين يجب أن يعمل).
- رسائل الخطأ العربية تبقى كما هي.
- لا comments جديدة غير ضرورية.

في رسالتك الأخيرة اذكر: نتائج كل خطوة (أرقام دقيقة)، أي إصلاحات أجريتها، الوثائق المحدّثة، وحالة git status النهائية.
